# Сводка участков

Небольшая система вместо трёх учебных Excel: заготовка, потребность сварки и документация. Пользователь сам вставляет эти файлы на странице «Загрузка». После этого они не нужны: записи лежат в SQLite.

## Запуск в Docker

Из папки `pbs_test`:

```text
docker compose up --build
```

Открыть http://localhost:8000

На первой странице выбрать три файла из папки `seed` и нажать «Загрузить в систему». Пока файлы не вставлены, сводка пустая. Повторная загрузка не принимается, пока данные не удалены. Удаление всех записей спрятано внизу страницы «Загрузка»: нужна отметка и слово УДАЛИТЬ.

Правки хранятся в томе `pbs-data` и остаются после перезапуска. `docker compose down` том не удаляет. Чтобы начать заново с исходных Excel: `docker compose down -v`, затем снова `docker compose up --build`.

## Запуск без Docker

Нужен Python 3.12 или новее.

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

На macOS и Linux окружение включается так: `source .venv/bin/activate`.

Адрес тот же: http://127.0.0.1:8000

База создаётся в `data/app.db`. При старте Excel сам не читается: файлы вставляет пользователь. Повторный запуск не перечитывает их, если база уже есть.

## Как проверить задание

1. На странице «Загрузка» вставить три файла из папки `seed`. На сводке четыре проблемы заготовки: факт 1200, факт −5, повтор P-005, пустой факт P-007.
2. Запомнить процент документации: 69,2% (18 из 26).
3. В «Заготовке» исправить факт P-003 с 1200 на 100 и сохранить.
4. На сводке выполнение заготовки и покрытие сварки меняются, документация остаётся 69,2%. Партия LOT-03 получает нормальное покрытие.
5. Скачать отчёт за период.
6. Остановить программу и запустить снова. Исправление на месте. Файлы из `seed` можно убрать: программа их больше не открывает.

Контрольный пример из исходного файла — ссылка «5–6 октября»: план 200, факт 190, выполнение 95,0%.

## Как считаются итоги

Выполнение плана = сумма факта / сумма плана по достоверным строкам. Это не среднее процентов.

Строка заготовки недостоверна, если факт пустой, меньше нуля или больше плана в два раза (строго больше, чем план × 2), если план не больше нуля, или если `record_id` повторяется. Обе копии дубля исключаются, чтобы факт не сложился дважды.

Покрытие сварки считается по номеру партии и только там, где есть одна достоверная заготовка. Остальные партии в процент не входят.

Ноль — введённое значение, он в итог входит. Пустая ячейка — пропуск.

Документация считается отдельно.
